##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Kiryu/Hey-You.git
cd Hey-You
```

### 2. Install dependencies

```bash
flutter pub get
```

### 3. Run the application

Bisa gunain emulator android studio atau yang lainnya, bebas suka suka kalian.

```bash
flutter run
```

##  Build APK

FYI, kalau lu mau mencoba aplikasinya tetapi ternyata **DEVELOPER GANTENG INI LUPA NGASIH RELEASE APK**, jangan panik ○( ＾皿＾)っ Hehehe…

Lu bisa membangun APK sendiri menggunakan source code yang tersedia.

```bash
flutter pub get
flutter build apk --release
```

Kalau build berhasil, APK biasanya tersedia di:

```text
build/app/outputs/flutter-apk/app-release.apk
```

Tinggal pindahkan file tersebut ke perangkat Android dan instal. Jika proses build gagal, periksa pesan error dan konfigurasi Android project terlebih dahulu.
